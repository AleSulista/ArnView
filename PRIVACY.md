# ArnView — Privacidade e processamento local

## Resumo

O ArnView 0.7.9 foi projetado para executar localmente no computador as funções integradas de visualização, edição, visão computacional e processamento inteligente sempre que aplicável.

## Imagens do usuário

As imagens abertas e editadas pelo ArnView são processadas no computador durante o uso normal das ferramentas distribuídas na versão 0.7.9. Os mecanismos integrados não dependem, por padrão, do envio das imagens para um serviço externo de IA para realizar as funções descritas na documentação pública desta versão.

## Modelos e motores locais

A distribuição inclui, quando necessário, modelos, frameworks e executáveis auxiliares integrados ao pacote do aplicativo para permitir processamento local.

## Serviços e componentes de terceiros

Frameworks do sistema operacional e componentes de terceiros permanecem sujeitos às políticas e condições de seus respectivos fornecedores. Este documento descreve o comportamento pretendido do ArnView e não substitui políticas do macOS ou de componentes externos.

## Alterações futuras

Caso uma versão futura passe a utilizar serviços online para alguma função, a documentação correspondente deverá identificar essa mudança.
